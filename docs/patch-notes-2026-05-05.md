# Patch Notes — May 5, 2026

## Improvements

### Themed Scrollbars

- Scrollbars across in-game windows (Auction House, Shop, Locker, Settings, Quest log, Trade, and others that previously used the browser default) now use the slim, accent-tinted scrollbar style and follow your chosen color scheme.

## Bug Fixes

### Auction House

- The Auction House window no longer grows taller as more listings are added — it now opens at a fixed height and scrolls inside the list area instead. Browse pagination (25 per page) is unchanged.

### AFK Emote

- Sending a chat message now resets your AFK timer, so the sleep emote no longer pops over your character while you're actively talking.

### Aura Particles

- Aura particle effects no longer freeze in place when an admin reloads the aura configs while you're online.
